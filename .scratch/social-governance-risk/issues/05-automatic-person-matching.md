# 05 — 自动人员匹配与档案详情

**What to build:** 合格事件自动匹配或建立人员档案，中心查看关联事件及身份差异。

**Blocked by:** 04 — 单条事件录入、草稿与原始追溯

**Status:** ready-for-agent

- [ ] 身份证号与姓名一致才自动匹配；新身份无冲突自动建档，手机号差异不覆盖档案。
- [ ] 无身份证号时仅姓名加有效手机号唯一无冲突可自动匹配；异常进入身份待审。
- [ ] 详情区分身份已确认与尚待重复检测的事件；此时不提前计入有效次数。

交付约束：包含完成上述行为所需的数据持久化、真实业务 API、可操作界面及外部行为验证，并更新相关操作或接口说明。审计和原始追溯随对应行为实现；新接入渠道复用统一处理入口。仅在全部前置任务完成后开工，状态不代表已实现或验收通过。
