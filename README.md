# 社会治理数据分析与风险预警系统

本项目的需求已于 2026-10-17 经逐项访谈确认。已提供 Spring Boot 后端、Vue 前端及 MySQL 迁移：登录与权限内事件、部门账号与角色兼任管理、数据来源与标准分类维护，以及事件录入、人员匹配、身份审核、重复归集和可解释人员风险。Compose 启动验收仍受 Docker Hub 镜像下载 EOF 阻挡。
