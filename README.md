# 社会治理数据分析与风险预警系统

本项目的需求已于 2026-10-17 经逐项访谈确认。当前交付为需求与设计文档，尚未实现前后端应用。

- [实施任务索引](.scratch/social-governance-risk/README.md)：已确认并发布的 32 项独立任务，含 96 条验收标准和依赖图。
- [项目规格说明书（to-spec）](docs/项目规格说明书.md)：按统一模板综合全部对话，包含用户故事、实现决定、测试建议及范围边界。
- [需求规格与决策记录](docs/需求规格.md)：确认范围、业务规则、权限和全部 44 项访谈决策。
- [数据模型设计](docs/数据模型设计.md)：保留现有事件主表的扩展方案，以及数据关系、状态和一致性要求。
- [验收清单](docs/验收清单.md)：26 项功能映射、核心业务场景、交付和规模验证要求。

技术栈：Vue 3、TypeScript、Element Plus、Spring Boot、MySQL 8.0。计划同时提供本机开发启动和 Docker Compose 部署。

需求依据为用户提供的课题 Word、事件主表 Markdown，以及本轮访谈确认。原文中的建议并不全部自动成为需求；存在差异时，以访谈确认结果为准。设计文档中的技术拆分属于实现建议，不新增业务范围。
