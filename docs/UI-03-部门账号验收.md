# UI 03 部门与账号管理

延续已确认的墨绿政务工作台风格，完成部门与账号页的查询、列表及编辑流程。当前交付对应任务 03，任务 04–12 保持待实施。

## 实现

- 概况卡片展示真实部门数、账号数和启用账号数；启用数仅按账号自身状态统计，旁有口径说明。
- 查询支持账号、姓名、部门关键词（英文不区分大小写）、归属部门与启用状态组合，部门页按名称与状态查询。Enter 或查询按钮应用条件，重置恢复全部，切换标签清空条件。
- 列表展示角色标签、启停状态、结果计数与总量。宽表格在容器内横向滚动，编辑列固定右侧；长文本省略并提供完整提示。
- 账号弹窗分为基本信息、角色权限和安全设置；部门弹窗保留单位类型创建后不可修改的约束。支持角色兼任、密码显隐、密码重置留空不修改及启用状态设置。
- 弹窗内部滚动，标题和底部操作持续可见。保存期间禁用表单与关闭操作，阻止重复请求；关闭账号弹窗清空密码。必填提示、密码要求与原服务端错误一同呈现。
- 样式集中于 `frontend/src/accounts.css`，限定在账号工作区、卡片及弹窗，沿用现有主题变量。复用既有接口及权限规则，无后端或数据库迁移改动。
