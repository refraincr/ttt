# UI 06 归集与风险研判

完成第 06 项，后续 07–12 保持待实施。

## 实现

- 延续墨绿工作台主题，以核对来源、确认归集、研判风险说明处理流程。人员档案、重复审核池、关键词规则与来源核查统一采用白色卡片、筛选区、结果计数、状态标签和证据分组。
- 风险依据分别展示有效事件次数、来源上报记录数和关键词命中条目；基础等级、规则等级、有效人工调整及最终等级分开显示，保留当前规则版本与最近有效事件时间。
- 有效事件可展开全部来源，进入来源核查；关键词命中保留原文高亮。来源核查保留地址、描述、候选、重复审核、人工标签及处理历史，必填理由可识别。
- “规则与批量接入”的误命中与人工调整标签同步优化等级概览、理由表单及历史表格，保留人工调整保存、误命中排除和依据失效行为。规则发布、导入等标签继续留待各自任务处理。
- 查询可重置；请求中展示处理状态并禁用重复动作；失败保留原记录与输入。读取新来源成功后清空上一条记录的审核结论、目标及理由。
- 窄屏四个研判标签采用两行排列，避免横向裁切导致入口无法点击；表单自动换行，宽表格在容器中横向滚动。
