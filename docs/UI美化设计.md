# 全项目 UI 美化设计

## 访谈状态

用户已确认设计方向、整体实施方案及 12 项任务拆分，已发布[正式任务索引](../.scratch/ui-refresh/README.md)。01 工作台框架与事件查询样板已完成，见[验收记录](UI-01-工作台验收.md)。

## 已确认

- 覆盖目标：整个项目的 UI。
- 视觉方向：精致政务工作台。
- 延续墨绿主色，优化字体、留白、表格和表单层次，保持稳重、适合长时间办公的视觉气质。
- 改版深度：视觉与布局一起优化。统一全部页面样式，同时重新组织筛选区、操作按钮、表单分组与详情层次，保留现有业务功能。
- 设备优先级：电脑办公优先，兼顾窄屏。重点适配笔记本和桌面显示器，小屏下内容自动换行，宽表格支持横向滚动。
- 信息密度：均衡办公型。留白适中、筛选区清楚、表格便于扫描、主要操作突出，兼顾精致感与日常办公效率。

## 实施方案（已确认）

- 全局框架：保留左侧业务导航与顶部账号区，统一导航选中态、页面标题、内容宽度与间距。
- 视觉规范：墨绿主色、浅灰背景与白色卡片，统一字体层级、圆角、边框、轻阴影及组件状态。
- 查询列表：统一筛选区、查询和重置操作、表格标题、数据计数、状态标签与分页；宽表格可横向滚动。
- 表单与详情：按内容分组，明确必填项与操作层级，统一弹窗、抽屉、校验反馈、加载及空状态。
- 业务页面：覆盖登录页及全部九个业务模块；业务概况页强化真实指标的阅读层次。
- 功能边界：保留现有业务规则、权限、接口与功能入口；本次调整展示与交互布局。
- 验证：完成类型检查与构建，并验证主要页面和交互及桌面、窄屏布局，具体执行结果交付时记录。

## 现状依据

- 项目使用 Vue 3、TypeScript 和 Element Plus。
- 现有界面采用深绿侧栏和浅色内容区，包含登录页与九个业务导航入口。
- 页面覆盖事件列表、归集与风险、录入与身份处理、部门与账号、来源与分类、规则与批量接入、修正与归档审核、预警与处置、业务概况与追溯。
- 公共样式与各页面局部样式共同控制布局，存在表格、筛选表单、标签页、弹窗和详情抽屉等多种界面形态。
