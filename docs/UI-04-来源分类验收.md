# UI 04 来源与分类维护

延续墨绿工作台主题，完成任务 04 的查询、列表和编辑流程。任务 05–12 保持待实施。

## 实现

- 概况卡片分别展示真实来源数、事件类别数、纠纷类型数；管理员包含启停配置，普通账号仅统计接口返回的可用项。
- 来源按名称/部门关键词、类型、状态组合查询；分类按名称/编码关键词、字典类别、状态查询。关键词忽略英文大小写，Enter 或查询按钮应用条件，重置与标签切换清空条件。
- 来源类型、分类类别和启停状态使用标签；表格展示结果数与配置总量，长文本提供完整提示，宽表格在容器内滚动，编辑列固定右侧。
- 来源弹窗分组展示来源信息、使用范围与状态；分类弹窗分组展示分类信息和使用状态。保存按钮固定在底部，弹窗内部滚动。保存期间禁用表单和关闭操作，阻止重复请求。
- 保留管理员维护、普通账号只读、停用保留历史解释，以及来源部门、分类编码与类别创建后不可修改的规则。必填标记与原服务端校验反馈保留。
- 样式限定于 `catalog-workspace`、`catalog-card` 和 `catalog-dialog`，沿用工作台变量。无后端、数据库或权限规则变更。
