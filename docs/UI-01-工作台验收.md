# UI 01 工作台框架与事件查询样板

实现范围：登录后的工作台框架、事件查询列表与详情。复用原来的会话、接口和角色判断，保留姓名或描述、关键词、部门与上传时间筛选，以及分页、重置、详情、刷新和退出。

## 公共视觉约定

- `frontend/src/workspace.css` 作为增量主题，在原有样式之后加载。`.workspace` 下提供 `--workspace-primary`、`--workspace-ink`、`--workspace-muted`、`--workspace-border`、`--workspace-surface`、`--workspace-radius`、`--workspace-shadow`，并同步 Element Plus 主色阶。
- 桌面使用墨绿导航、白色账号区与浅灰内容背景。卡片采用 12px 圆角和轻阴影，输入区、主要动作、结果标题与分页各有独立层次。字体沿用项目系统字体，不增加外部字体请求。
- 事件页样式限定在 `.event-workspace`，详情限定在 `.event-detail-drawer`；后续页面可逐步采用上述变量。原页面仍使用既有页面样式。
- `WorkspaceNavigation.vue` 复用桌面与移动端的入口和角色规则，当前项使用 `aria-current="page"`。760px 以下以 Element Plus 抽屉提供导航，支持关闭、Escape 与焦点恢复，选择后自动收起。
- 日期筛选在桌面分为三列文本、两列日期；窄屏单列。宽表格在自身容器滚动，操作列固定右侧。详情按当事人信息、事件信息和问题描述分组，长文本换行，关闭按钮固定在抽屉底部。
- 原来的全局 `header` 规则收敛为 `.workspace-header`，避免影响所有业务抽屉标题。
