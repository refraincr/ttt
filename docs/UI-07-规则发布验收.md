# UI 07 规则草稿、预览与发布

## 实现

- 采用墨绿、浅灰背景与白色卡片，当前生效规则展示版本、次数阈值和启用关键词数；编辑保存、影响预览、发布重算以三步说明引导。
- 草稿区分新草稿、已保存修订与未保存修改。次数阈值与关键词规则分组，规则名称、关键词组合及启用状态保留原有接口和业务含义。
- 从当前生效配置新建，或在版本列表编辑草稿、复制配置。只有保存当前修改后才能预览，只有当前草稿预览成功后才能发布；修改配置立即清空旧预览，避免预览或发布旧保存内容。
- 影响预览明确展示等级变化、升级和降级人数，零影响仍可正常发布。版本及重算状态采用中文标签；重算保留已完成 / 总人数、对应版本、失败原因与重试操作。
- 加载期间禁用编辑及重复操作；校验、预览和发布失败保留输入。长失败原因可展开阅读全文。刷新沿用现有接口，重算进度由用户刷新读取。
- 窄屏标签采用两列排列，现有批量导入、人工调整、来源映射及外部接入入口保持可访问。宽表格在容器内横向滚动。
