# UI 10：预警研判与部门处置

对应任务：[10 预警研判与部门处置](../.scratch/ui-refresh/issues/10-warning-case-handling.md)。沿用墨绿主色、浅灰背景、白色卡片与均衡办公密度。

## 页面与交互

- 增加按角色展示的流程提示和操作范围；中心查看风险预警、派发与审核，承办部门查看本部门授权任务。
- 预警筛选按风险、姓名、关键词、来源、部门及时间分组，增加重置入口；提醒阈值单独呈现。列表区分风险等级、预警状态、新增依据与未研判积压。
- 预警详情集中展示预警等级、当前风险和依据事件数；保留来源原文、关键词命中、研判历史。研判与授权派发表单分组，必填项、最小授权提示及提交动作明确。
- 任务列表区分任务阶段、归档待确认、部门逾期与中心待审时间。任务详情保留当前授权信息、派发快照、附件及完整跟进审核历史。
- 部门跟进、结果提交、中心退回或通过、明确办结关联事件及归档变化确认入口全部保留。归档确认字段增加标签，历史确认动作显示中文名称。
- 读取和提交期间显示状态，相关输入、附件移除、分页与动作禁用，失败保留输入并支持原入口重试。空列表和空历史提供明确文案。
- 宽表格在容器内横向滚动；窄屏表单改为单列、按钮换行、长文本完整展示。归档确认人员编号使用原生数字输入，避免现有数字步进组件在忙碌期间挂载后残留禁用的无障碍标记。
