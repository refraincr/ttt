# UI 11 业务概况、导出与操作追溯

## 实现

- 概况沿用墨绿主色、浅灰背景与白色卡片；当前账号视角、查询范围、八项真实指标、来源部门分布及热点关键词分组展示。部门条形长度按接口返回数量相对最大值计算，不添加模拟业务指标。
- 输入与已提交筛选分开：只有查询成功后才替换概况、事件、风险及导出条件。查询成功清除旧关键词下钻结果；翻页沿用已提交筛选。查询失败保留上次成功数据及对应导出范围，显示错误并允许重试。
- 热点关键词下钻沿用现有接口，明确当前关键词与命中数量；完整依据可展开。人员与事件详情沿用现有抽屉，保留风险等级、联系方式、归集来源、联系地址与关键词原文。
- 导出区明确对应已提交查询和账号权限；部门账号不显示完整风险导出或中心风险明细。尚未成功查询或请求处理中暂不提供导出链接。
- 操作历史按对象、人员与起止时间查询，编号与时间先做基本校验；保留完整记录展开、每页十条及翻页。未查询和查询无结果使用不同提示。
- 请求处理中禁用重复操作；各查询失败保留已有数据及输入。主页面样式集中在 `frontend/src/insights.css`，抽屉局部样式仍在组件内。
