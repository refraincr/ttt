# UI 05 事件录入与身份处理

完成 UI 任务 05，后续 06–12 保持待实施。

## 实现

- 延续墨绿工作台主题，以录入留存、身份确认、重复筛查说明处理流程。表单分组展示当事人、事件及上报来源，提交必填项与草稿暂存提示分开说明。
- 保留草稿创建、编辑、保存、删除和提交；展示最近记录编号、身份状态及归集结果。提交期间阻止重复请求，失败保留输入并清除过期成功提示。
- 来源记录展示身份与重复状态、当事人信息、问题描述、关键词证据、格式化提交原文和重复候选；查询完成后同步替换记录与候选。
- 人员档案、身份审核及重复筛查设置保留中心角色入口，部门仅能录入和读取权限内来源记录。审核支持关联档案、受控建档、理由校验及取消。
- 桌面双列表单，窄屏单列；宽表格在容器内滚动。1440 和 1280 下草稿位于表单后，更宽桌面并排展示。
