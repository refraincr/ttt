# 联系地址与事件关键词

事件列表及详情增加当事人身份证号、电话、联系地址和关键词。关键词为现有人工标签（keyword_tags），独立筛选按字面包含匹配，可与当事人/描述、部门和上传时间组合；查询、翻页、重置均保留原权限规则。

联系地址使用原表 party_address，接口字段为 address，允许留空，提交时去除两端空白，最多500字。地址保存在每条来源记录，不参与人员身份匹配，也不自动覆盖其他来源。手工录入、草稿、来源修正申请及审核、事件详情、人员档案来源记录、事件CSV导出均支持地址。旧客户端修正未传 address 时保留已有地址，明确传空字符串时清空。

CSV/Excel统一模板追加“联系地址”列；旧中文/英文字段模板继续接受，缺少地址视为空。自定义来源映射可选择 address 对应列，不接入时在界面清空地址列名。外部接收接口 payload.address 同样适用。地址参与有值时的文件去重依据，未传或空地址不改变旧文件的字段序列；外部编号幂等机制保持不变。

验证覆盖手工录入/草稿、地址修正、关键词字面匹配、部门隔离、CSV/Excel和自定义映射、超长地址逐行报错、文件重导及外部接入幂等。新库与现有库不需要新增迁移。
