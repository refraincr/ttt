# UI 08 批量导入、映射与接入管理

## 实现

- 批量导入拆分为概况、三步指引、上传表单与批次列表；概况从当前接口数据汇总批次数、待处理行与失败行，不改变统计口径。
- 来源和映射明确标注；选择来源后可下载 CSV / Excel 模板，切换来源清空旧映射。文件输入、大小与行数限制、日期示例和失败重导说明集中展示。
- 批次保留总数、待处理、成功、重复、失败、逐行结果、失败文件和原文件；增加中文处理状态，长文件名可悬停查看，窄屏表格内部横向滚动。
- 沿用既有逐行结果弹窗、自动刷新和关闭行为。下载失败文件后使用相同来源与映射修正重导，重复记录仍按现有接口处理。
- 来源映射直接选择来源，分组维护版本名称、文件列名、日期转换与分类别名；显示该来源已有版本。保存仍调用原有版本接口，失败保留输入，加载期间禁用编辑。
- 管理员凭据表单分组展示可信归属和上报权限；列表使用来源名称与中文启停状态。新令牌仅在创建响应后显示，可主动隐藏，列表和截图均不包含真实令牌。
- 外部接收结果保留凭据、外部编号、来源记录、失败原因与接收时间；增加结果标签，长失败原因可展开查看。
- 角色权限、后端接口和业务规则保持现有实现；没有新增接入渠道、数据库或风险规则变更。
