# UI 02 登录页与身份反馈

登录页采用工作台已有墨绿配色、浅灰背景与白色卡片。桌面左侧按品牌、业务介绍和系统名称分层，右侧集中呈现账号、密码、主要操作、权限说明与演示环境说明；窄屏保留品牌和两行介绍，表单改为单列。

## 实现范围

- `frontend/src/login.css` 管理登录布局，清理 `style.css` 中被替代的旧登录样式；共享主题变量从 `.workspace` 扩展到 `.login-layout`，后续业务页面仍沿用原有样式。
- 保留真实会话、CSRF、登录、身份查询、权限判断和退出流程。账号继续去除首尾空白，密码保持原值；成功后清空密码。
- 提交时显示“正在登录…”和可被辅助技术读取的状态，账号与密码暂时禁用，提交函数阻止并发重复请求。输入保留自动填充与密码显隐，表单标签关联到真实输入框，支持 Enter 提交和键盘操作。
- 错误通过原有提示显示，空值校验不请求登录接口，失败后可修改并重试。演示说明使用真实环境描述，无新增登录方式、业务接口或数据库改动。
